Three ways to estimate the effect

unadjusted <- lm(y ~ treatment, data = d)

adjusted <- lm(y ~ treatment + weight + age, data = d)

propensity_model <- glm(
  treatment ~ weight + age,
  family = binomial(),
  data = d
)
d_wts <- propensity_model |>
  augment(data = d, type.predict = "response") |>
  mutate(wts = wt_ate(.fitted, treatment, exposure_type = "binary"))
outcome_model <- lm(y ~ treatment, data = d_wts, weights = wts)
weighted <- ipw(propensity_model, outcome_model)

ipw() uses a sandwich estimator that also accounts for the uncertainty in the propensity score model

Conditional vs. marginal effects

  • Direct adjustment gives a conditional effect: holding the other variables constant
  • Weighting gives a marginal effect: averaged over the population
  • With a continuous outcome, a linear effect, and no interactions, the two are identical

The wrong functional form

lm(satisfaction ~ update_frequency + num_users, data = d) |>
  tidy(conf.int = TRUE) |>
  filter(term == "update_frequencydaily") |>
  select(estimate, starts_with("conf"))
# A tibble: 1 × 3
  estimate conf.low conf.high
     <dbl>    <dbl>     <dbl>
1   -0.189   -0.219    -0.159
  • The estimate is far from the truth, which is not even contained in the confidence interval

A flexible functional form

lm(
  satisfaction ~ update_frequency + splines::ns(num_users, 3),
  data = d
) |>
  tidy(conf.int = TRUE) |>
  filter(term == "update_frequencydaily") |>
  select(estimate, starts_with("conf"))
# A tibble: 1 × 3
  estimate conf.low conf.high
     <dbl>    <dbl>     <dbl>
1  0.00216 -0.00258   0.00690
  • We often do not know the data-generating mechanism, but we can still fit flexible parametric models
