Model-level diagnostics

Before weighting, we checked the calibration, the ROC curve, and the AUC of the propensity score model

Now: did weighting remove what the model knew?

Weighted ROC curve



If the weights did their job, the model should no longer discriminate between the exposure groups

Weighted AUC

  • In a prediction model, a weighted AUC of 0.50 would be a failure
  • In a causal model, it means the confounders no longer tell the groups apart

Effective sample size

\[\LARGE ESS = \frac{(\sum_{i=1}^{n} w_i)^2}{\sum_{i=1}^{n} w_i^2}\]

The approximate number of independent observations after weighting

The grouped values do not sum to the total: each measures the variation in a different set of weights

Where does the variation come from?

The price of balance

  • Weighting introduces variation, so precision drops
  • The more variable the weights, the lower the ESS
  • If the ESS is too small: different weights, or trimming and truncation

Variable-level diagnostics

Exchangeability means the groups are exchangeable within levels of the confounders

A consequence: exchangeable groups are balanced at the variable level

Standardized Mean Difference (SMD)

\[\LARGE d = \frac{\bar{x}_{treatment}-\bar{x}_{control}}{\sqrt{\frac{s^2_{treatment}+s^2_{control}}{2}}}\]

Weighted ECDF for temperature

A non-linear relationship

  • The weighted curves overlap until about 27 degrees, then they diverge
  • The SMD for temperature is near zero, so it would have missed this
  • Let’s refit the propensity score model with a natural spline

Refit with a spline

propensity_model_ns <- glm(
  net ~ income + health + splines::ns(temperature, df = 5),
  family = binomial(),
  data = net_data
)

net_data_ns <- propensity_model_ns |>
  augment(type.predict = "response", data = net_data) |>
  mutate(w_ate = wt_ate(.fitted, net))

Balance across the joint distribution

Exchangeability requires balance across the joint distribution of the confounders

That includes interactions between variables and higher moments

Interactions and squares

balance_metrics_joint <- check_balance(
  net_data_ns,
  .vars = all_of(vars),
  .exposure = net,
  .weights = w_ate,
  interactions = TRUE,
  squares = TRUE
)

balance_metrics_joint |>
  filter(metric %in% c("smd", "vr")) |>
  plot_balance(facet_scales = "free_x")

Interactions and squares

Energy

The average distance across the joint ECDFs: one number for the whole covariate space

The scale depends on the confounders, so use energy to compare approaches

Don’t use p-values

  • Balance is a property of the sample; p-values refer to a hypothetical population
  • p-values depend on sample size: dropping observations at random “improves” them
  • There is no theoretical link between a p-value cut-off and good balance

Imai, King, and Stuart (2008)
